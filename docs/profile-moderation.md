# 프로필 숨김 배포

백엔드 배포 전에 `202611180001_admin_profile_moderation.sql`을 적용합니다. 새 `admin_hidden` 열은 마지막 `member_publication_updated` 감사 로그의 공개 결정을 복원합니다. 삭제되었거나 누락된 감사 로그는 자동 복원할 수 없으므로 운영자가 이전 숨김 대상을 확인해야 합니다.

관리자 숨김은 공개 프로필 목록·상세, 새 추천 후보, 새 연락 요청에 적용됩니다. 소유자의 프로필 수정과 공개 토글은 관리자 숨김을 해제하지 않습니다. 직접 데이터베이스 접근에서 일반 사용자의 숨김 상태 변경과 숨겨진 프로필 삭제도 거부됩니다. 관리자 API에서 공개를 허용하면 해제됩니다.

프로젝트 게시물은 별도의 공개 설정을 유지합니다. 전체 사용자 이용 정지가 필요한 정책은 별도 기능입니다. 운영 데이터베이스에 적용하기 전에 임시 PostgreSQL 데이터베이스에서 `backend/test/sql/profile-privacy.sql`을 실행하세요.
